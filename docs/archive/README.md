# Historical archive

These documents preserve the project's earlier plans, requirements, design,
research, and release draft. Their original status labels, proposed behavior,
and incomplete checklists are historical records. They are not current policy,
instructions, requirements, a task queue, or a source of truth. Do not update
historical documents unless the user requests it.

Archiving does not complete or waive unfinished work. See the current
[release status](../release-status.md) for remaining work and validation,
[documentation index](../README.md) for current documents, and
[repository instructions](../../AGENTS.md) for current policy.
