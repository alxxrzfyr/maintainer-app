# Maintainer 1.2.0

Maintainer 1.2.0 makes everyday monitoring clearer and critical maintenance more dependable. Network activity and running processes now have dedicated pages, temperature information is easier to understand, and the interface is more consistent throughout.

## What’s new

- A dedicated Network page with live download and upload activity, connection details, Wi-Fi information, and recent activity history.
- An optional internet speed test with latency, download, and upload results.
- A dedicated Processes page with sorting and safe process controls.
- Clearer grouped temperature readings without repeated or invalid sensor values.
- Refined navigation, icons, spacing, colors, cards, buttons, and status messages in both themes.

## More dependable updates

System updates now provide clearer progress and safer controls throughout the operation. Maintainer reports success only after confirming that the reviewed updates were actually installed.

Critical actions reliably request administrator authentication. Irreversible actions ask each time, while low-risk actions such as refreshing disk health information remain convenient for an active local session.

## Privacy

Passive network monitoring stays entirely on the computer and does not contact an external service. The internet speed test is optional, clearly identifies Cloudflare before it starts, explains its approximate data use, and does not save the results.

## Upgrading

The Debian package installs the matching application and privileged components. Close an older Maintainer window before launching 1.2.0 to ensure the new version opens instead of forwarding to an existing process.

No release tag or downloadable package has been published yet.
