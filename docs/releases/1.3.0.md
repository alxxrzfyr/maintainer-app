# Maintainer 1.3.0

Draft release notes. This version has not been published. Performance and manual
acceptance remain open in [release status](../release-status.md).

Maintainer 1.3.0 improves reviewed maintenance, desktop responsiveness, and
diagnostic accuracy on Ubuntu-based Linux systems.

## Highlights

- Review exact native APT package changes before approval. Transactions retain
  their plan, record durable receipts, support Resume, and inhibit shutdown/sleep
  during package mutation and verification.
- Review regular-file cleanup with protected quarantine and recovery. Retained
  file identities protect against path substitutions; duplicates remain opt-in.
- Keep monitoring and diagnostics responsive with bounded workers, incremental
  widgets, lazy pages, and background hardware inventory.
- Distinguish observed hardware information from missing or unverified values.
  Duplicate rows and speed-test workflows have behavioral GTK regression tests.
- Preview redacted reports and export new private files without overwriting
  existing names. Settings/history storage supports private backup and recovery
  with Ubuntu 22.04's system SQLite.

## Compatibility and limits

- Target platforms: Ubuntu 22.04+ and compatible derivatives, on `amd64` and
  `arm64`, with an X11 or Wayland desktop.
- Optional integrations report missing capabilities. Unprobed graphics
  acceleration remains unverified.
- Cleanup supports reviewed regular files on supported filesystems; folder
  deletion and automatic duplicate deletion are unavailable.
- Cancellation respects operation boundaries. Interrupted APT work may require
  repair through the system package manager; there is no automatic rollback.
- Reports require preview before sharing. Redaction reduces disclosure risk
  but does not replace review.
